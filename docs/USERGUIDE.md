# Picsoc 使用手册

Picsoc 将已有图片文件夹整理成可浏览、搜索和打标签的素材库。原图保留在原位置，收藏、标签和缩略图保存到服务的数据目录。安装、源码运行和 Docker 配置见 [README](../README.md)。

## 第一次使用

1. 启动 Picsoc，在浏览器打开服务地址；本机默认是 `http://127.0.0.1:3210`。
2. 点击顶部“添加素材库”，选择“选择文件夹”。
3. 从常用位置进入素材文件夹，点击“选择此文件夹”；也可以手动填写绝对路径。
4. 为素材库起一个方便识别的名字，确认添加。
5. 图片随后台扫描逐步出现，可以继续浏览已经索引的素材。

文件夹选择器显示的是**运行 Picsoc 服务的机器**：

| 使用方式 | 应选择的路径 |
| --- | --- |
| 本机原生服务 | 本机目录，例如 Windows 的 `D:\Pictures` |
| 浏览器连接另一台电脑或服务器 | 那台服务机器上的目录 |
| 本仓库的 Docker Compose | 容器内的 `/library` 或其子文件夹 |

这里没有上传本机文件的流程；从手机或另一台电脑打开页面，不会让选择器浏览那台设备的本地文件。Docker 中直接填写宿主机 `/home/...` 路径会失败，素材须先挂载到容器。选择器不列出隐藏点目录和符号链接；已有隐藏目录可以直接填写路径。

添加素材库只建立索引，不复制、移动、修改或删除原图。服务账号需要能够读取和遍历素材目录，数据目录需要可写。不要选择 Picsoc 自己的数据目录。

## 扫描、取消与重扫

添加目录后会自动递归扫描 JPEG、PNG、GIF、WebP、BMP 和 TIFF。启动服务时也会检查已保存的素材库；默认每 300 秒进行一次增量扫描。它只重新处理发生变化的图片。

| 状态 | 含义 |
| --- | --- |
| 正在扫描 | 正在遍历目录和建立索引，处理数量持续更新 |
| 准备就绪 | 本轮目录遍历和缩略图任务入队完成；部分缩略图可能还在后台生成 |
| 扫描异常 | 目录、权限或其他处理出现问题，可在素材库管理中查看具体说明 |

扫描期间可以浏览。图片先出现、缩略图稍后完成属于正常行为。较慢的机械硬盘或网络盘需要更多时间。

通过左侧素材库的管理按钮可以查看目录及扫描状态，选择“重新扫描”主动检查新增、修改和缺失的图片。修复临时权限或磁盘问题后，手动重扫会重试失败的缩略图；定时扫描不会反复解码未变化的坏图。

扫描进行时，可点击扫描提示条右侧或素材库管理窗口中的“取消扫描”。提交后显示“正在取消…”，等待服务确认结束；不要重复点击。取消扫描保留已建立的索引，并且不会按不完整的遍历结果移除旧素材。取消后已排队的缩略图任务可能继续完成。关闭浏览器不会取消扫描；要停止整个服务，在原生运行终端按 `Ctrl+C`，或按 Docker 运维说明停止容器。

管理脚本也可以使用 [API 文档](API.md) 中的扫描取消接口。关闭定时扫描使用 `--scan-interval 0`，或 Docker 的 `PICSOC_SCAN_INTERVAL=0`；服务启动和手动重扫仍可运行。

## 浏览与子文件夹

“全部素材”显示所有素材库的图片；点击左侧某个素材库，查看该库。工具栏可选择大图、中图或紧凑网格。

选择素材库后，搜索栏下方显示文件夹导航：

- 点击子文件夹进入；导航上的数字包含其后代目录中的图片。
- 当前页面显示该目录及后代目录内的所有图片。
- 点击面包屑中的素材库名称回到整个库，点击中间目录或“上一级”返回。
- 每层只显示索引中包含图片的目录，空目录不显示。扫描完成前可能还未出现全部目录。
- 较多子目录先折叠显示，可以展开；接口每层最多列出 1,000 个目录，出现提示时可继续进入子目录逐层浏览。

子文件夹浏览使用已有索引，与添加素材库时的系统文件夹选择器用途不同。它不会创建、改名或移动原始文件夹。

## 搜索与筛选

搜索框匹配文件名、相对路径和标签中的文字，支持中文。左侧点击标签时，按完整标签筛选。工具栏可按 JPG、PNG、GIF、WebP、BMP 或 TIFF 筛选，排序支持最近修改、名称和文件大小。

“我的收藏”显示收藏素材。素材库、子文件夹、搜索、格式和标签筛选可以组合使用；出现筛选提示后，点击单个条件的关闭按钮移除它，或“清除筛选”清空搜索、格式和标签。回到素材库面包屑根位置可解除子目录范围，选择“全部素材”可切回所有库。

没有结果时，先检查当前素材库与文件夹范围、筛选条件，以及扫描是否完成。右上方的刷新按钮重新读取列表和统计信息；更新文件索引需要“重新扫描”，两者用途不同。

## 收藏与标签

点击图片卡片的星标收藏或取消收藏；在预览窗口中也可以操作。收藏保存到服务数据库，在其他设备使用同一个服务时也能看到。

点击图片打开预览，在“标签”中输入新标签，按 Enter 添加。多个标签可用英文/中文逗号、分号或换行分隔。点击已有标签的关闭按钮移除，最后点击“保存标签”提交修改；离开预览前保存需要保留的编辑。

每张图片最多 50 个标签，每个标签最多 50 个字符。标签前后空白会被去除，重复项合并。文件名和用户标签保持原文，切换界面语言不会翻译它们。

## 批量整理

1. 点击主区域的“批量整理”进入选择模式。
2. 点击卡片或勾选框选择素材，滚动后可以继续累积选择，最多 500 项。
3. “选择可见项”只选择当前真实视口中已经载入的素材，不会选择整库或其他未显示的结果。“清空”取消当前选择。
4. 点击“收藏”或“取消收藏”，也可以打开“管理标签”，选择添加或移除标签，输入标签或点选已有标签。
5. 提交后，成功提示会显示更新数量，列表刷新并清空选择；失败时保留选择，方便修正后重试。

批量添加标签会保留其他标签；批量移除只删除指定标签。不存在的标签移除没有副作用。一次操作中的任何素材不存在或标签数量超限时，整个批次都不修改，避免部分成功。

切换搜索、素材库、子文件夹、标签、格式或排序会清空选择，避免把上一组结果意外应用到新范围。点击“完成选择”退出选择模式；选择模式内点击卡片用于选择，退出后可以恢复图片预览。

## 图片预览与下载

点击卡片进入预览，用键盘 `←` / `→` 或界面箭头切换，按 `Esc` 关闭。右侧显示格式、尺寸、文件大小、修改日期、标签及相对路径。路径复制受浏览器权限限制时，可手动选中路径复制。

GIF 网格缩略图是首帧，原图预览保留动画。TIFF 通常不能由浏览器直接显示，因此预览使用缩略图，可下载原图查看完整画质。其他格式也受到浏览器解码支持限制；预览失败时仍可尝试“下载原图”。

单张图片超过 256 MiB 文件大小、128 MiB 解码预算或 32,768 像素宽/高时会跳过缩略图；原文件不会被删除。解码失败、原图不可访问或数据目录写入失败也可能影响预览。低配置服务建议保持 1 个图片 worker；同时打开多个大原图会另外消耗浏览器内存。

下载原图保留原文件内容，包括其中的元数据。Picsoc 当前没有图片编辑、压缩替换、视频管理或 AI 自动标签功能。

## 移除素材库与文件变化

在素材库管理中选择“移除素材库”，确认“移除索引”后，Picsoc 会删除这个库的索引、收藏、标签和缩略图，**原图仍留在文件夹中**。

再次添加相同目录可以重新索引图片，但不能恢复之前删除的收藏和标签。需要恢复旧元数据时，使用停止服务时制作的整个数据目录备份，见 [运维指南](OPERATIONS.md)。

在文件管理器中新增或修改图片后，通过增量扫描更新；删除图片后，成功重扫会清理对应索引。移动或改名目前视为删除旧素材并添加新素材，原来的收藏和标签不会自动转移。

不要在恢复原图之前启动指向空目录的服务：成功扫描会认为旧文件已不存在并清理索引。数据目录中的 SQLite 文件和缩略图也不要在服务运行时手动修改。

## 界面语言与服务连接

顶部语言选择器可以切换简体中文和 English，当前浏览器会记住选择。另一个浏览器或设备有独立的语言偏好；素材、标签和收藏仍由同一服务共享。

“服务连接异常”时，先确认服务仍在运行，访问地址正确，网络及密码可用，然后点击重试。密码认证用户名固定为 `picsoc`；远程访问与 HTTPS 配置见 [安全说明](../SECURITY.md) 和 [运维指南](OPERATIONS.md)。
