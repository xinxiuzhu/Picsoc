# Picsoc 使用手册

Picsoc 将已有图片文件夹整理成可浏览、搜索和打标签的素材库。原图保留在原位置，收藏、标签和缩略图保存到服务的数据目录。安装、源码运行和 Docker 配置见 [README](../README.md)。

## 第一次使用

1. 启动 Picsoc，在浏览器打开服务地址；本机默认是 `http://127.0.0.1:3210`。
2. 点击顶部“添加素材库”，选择“选择文件夹”。
3. 从常用位置进入素材文件夹，点击“选择此文件夹”；也可以手动填写绝对路径。
4. 为素材库起一个方便识别的名字，确认添加。
5. 图片随后台扫描逐步出现，可以继续浏览已经索引的素材。

文件夹选择器显示的是**运行 Picsoc 服务的机器**：

| 使用方式 | 应选择的路径 |
| --- | --- |
| 本机原生服务 | 本机目录，例如 Windows 的 `D:\Pictures` |
| 浏览器连接另一台电脑或服务器 | 那台服务机器上的目录 |
| 本仓库的 Docker Compose | 容器内的 `/library` 或其子文件夹 |

这里没有上传本机文件的流程；从手机或另一台电脑打开页面，不会让选择器浏览那台设备的本地文件。Docker 中直接填写宿主机 `/home/...` 路径会失败，素材须先挂载到容器。选择器不列出隐藏点目录和符号链接；已有隐藏目录可以直接填写路径。

添加素材库只建立索引，不复制、移动、修改或删除原图。服务账号需要能够读取和遍历素材目录，数据目录需要可写。不要选择 Picsoc 自己的数据目录。

Apple Photos 的 `.photoslibrary` 是「照片」App 管理的图库包，扫描与文件夹选择器会跳过它。添加整个 `Pictures` 文件夹仍会索引其中的普通图片；不能直接添加图库包或其内部目录。

要整理「照片」App 中的图片，请在「照片」中选择图片，使用「文件」→「导出」→「导出照片」，选择 JPEG、PNG 或 TIFF，保存到图库包之外的普通文件夹，再添加导出文件夹。导出未修改原片可能得到尚不支持的 HEIC 格式。详见 [Apple 导出说明](https://support.apple.com/zh-cn/guide/photos/pht6e157c5f/mac)。

## 扫描、取消与重扫

添加目录后会自动递归扫描 JPEG、PNG、GIF、WebP、BMP 和 TIFF。启动服务时也会检查已保存的素材库；默认每 300 秒进行一次增量扫描。它只重新处理发生变化的图片。

素材库内部以点开头的隐藏目录（例如 `.git`、`.svn`、`.cache`）会被跳过，左侧也不会显示这些目录。旧版本已经索引过的隐藏目录图片，在成功重扫后移除相应索引与缓存，原文件保留；失败或取消扫描仍保留原有索引。若手动填写隐藏目录的绝对路径并将其作为独立素材库，其根目录本身不受这条内部目录规则影响。

若旧版本已在普通素材库下索引过 Photos 图库内部图片，跳过该包时会保留已有索引、收藏和标签，但不再更新包内图片。普通目录中新增、修改和删除的图片仍正常更新；普通目录出现读取错误时，仍会报告扫描异常并保留旧索引。

| 状态 | 含义 |
| --- | --- |
| 正在扫描 | 正在遍历目录和建立索引，处理数量持续更新 |
| 准备就绪 | 本轮目录遍历和缩略图任务入队完成；部分缩略图可能还在后台生成 |
| 扫描异常 | 目录、权限或其他处理出现问题，可在素材库管理中查看具体说明 |

扫描期间可以浏览。图片先出现、缩略图稍后完成属于正常行为。较慢的机械硬盘或网络盘需要更多时间。

通过左侧素材库的管理按钮可以查看目录及扫描状态，选择“重新扫描”主动检查新增、修改和缺失的图片。修复临时权限或磁盘问题后，手动重扫会重试失败的缩略图；定时扫描不会反复解码未变化的坏图。

扫描进行时，可点击扫描提示条右侧或素材库管理窗口中的“取消扫描”。提交后显示“正在取消…”，等待服务确认结束；不要重复点击。取消扫描保留已建立的索引，并且不会按不完整的遍历结果移除旧素材。取消后已排队的缩略图任务可能继续完成。关闭浏览器不会取消扫描；要停止整个服务，在原生运行终端按 `Ctrl+C`，或按 Docker 运维说明停止容器。

管理脚本也可以使用 [API 文档](API.md) 中的扫描取消接口。关闭定时扫描使用 `--scan-interval 0`，或 Docker 的 `PICSOC_SCAN_INTERVAL=0`；服务启动和手动重扫仍可运行。

## 浏览与子文件夹

“全部素材”显示所有素材库的图片；点击左侧某个素材库，查看该库。顶部“收起侧栏”隐藏左侧导航，为图片留出更多空间；“展开侧栏”恢复导航。桌面偏好会保存，手机则使用独立的抽屉，不随桌面偏好自动打开。

工具栏“显示设置”的“每行数量”可选择 1–12 张：数量增加时图块缩小，数量减少时图块变大；“自动排列”或大图、中图、紧凑三档快捷按钮会根据可用宽度自动分列。窄屏会限制实际列数，避免图片挤得太小，回到较宽窗口后恢复期望数量。

当前浏览器会记住显示设置，图片始终完整显示。这些操作不改变原文件、素材尺寸或服务端缓存，也不限制素材库的总结果数；滚动时继续按需加载后续图片。

点击素材库前的箭头展开左侧目录树，点击文件夹名称选择范围：

- 文件夹前的箭头只展开/折叠分支，不改变当前选择；名称右侧数字包含其后代目录中的图片。
- 默认显示该目录及后代图片，关闭“包含子文件夹”后只显示当前目录直接存放的图片，素材库根目录同样支持。
- 点击面包屑中的素材库名称回到整个库，点击中间目录或“上一级”返回。
- 真实空目录及只有其他文件的目录也显示。扫描完成前可能还未出现全部目录；已有素材库升级后重新扫描会补齐空目录。
- 每层按需加载 200 个目录，点击“加载更多文件夹”继续读取，避免一次展开大量目录。

子文件夹浏览使用已有索引，与添加素材库时的系统文件夹选择器用途不同。它不会创建、改名或移动原始文件夹。

## 搜索与筛选

搜索框匹配文件名、相对路径和标签中的文字，支持中文。左侧点击标签时，按完整标签筛选。点击工具栏的“筛选”，设置条件后选择“应用筛选”：

- 图片方向：横图（宽大于高）、竖图（高大于宽）、方图（宽高相等）。
- 宽高比：常用比例或自定义，例如 `16:9`、`1:1`、`2.35:1`；比例匹配允许 ±2% 相对误差。
- 像素宽高与文件大小：可以只填最小值、最大值，或两者；范围包含边界，文件大小输入单位为 MB。
- 格式与标签：按 JPG、PNG、GIF、WebP、BMP、TIFF 或完整标签筛选。
- 排除文件名：例如输入 `map` 后，文件名包含 `map` 或 `MAP` 的图片会隐藏；多个词用换行或中英文逗号分隔。当前浏览器会记住排除词，可以逐词移除；仅匹配文件名，原文件保留。
- 排序：最近修改、名称正序/倒序、文件大小从大到小/从小到大，以及宽度、高度、总像素从大到小。

尺寸尚未识别或解码失败的素材不会匹配方向、比例或像素范围；后台完成尺寸处理后列表会刷新。筛选面板中的“重置”先清空草稿，点击应用后生效，点击取消则保留原条件。

顶部搜索框可用 `⌘K`（macOS）、`Ctrl+K`（Windows/Linux）或非输入状态下的 `/` 快速聚焦。弹窗打开时不会抢走输入焦点。网格的显示数量独立于筛选，不改变结果总数。

“我的收藏”显示收藏素材。目录、关键词和所有图片筛选条件可以组合使用；出现筛选提示后，点击单个条件的关闭按钮移除它，或“清除筛选”清空条件并保留当前目录范围。回到素材库面包屑根位置可解除子目录范围，选择“全部素材”可切回所有库。

没有结果时，先检查当前素材库与文件夹范围、筛选条件，以及扫描是否完成。右上方的刷新按钮重新读取列表和统计信息；更新文件索引需要“重新扫描”，两者用途不同。

## 收藏与标签

点击图片卡片的星标收藏或取消收藏；在预览窗口中也可以操作。收藏保存到服务数据库，在其他设备使用同一个服务时也能看到。

点击图片打开预览，在“标签”中输入新标签，按 Enter 添加。多个标签可用英文/中文逗号、分号或换行分隔。点击已有标签的关闭按钮移除，最后点击“保存标签”提交修改；离开预览前保存需要保留的编辑。

每张图片最多 50 个标签，每个标签最多 50 个字符。标签前后空白会被去除，重复项合并。文件名和用户标签保持原文，切换界面语言不会翻译它们。

## 批量整理

1. 点击主区域的“批量整理”进入选择模式。
2. 点击卡片或勾选框选择素材，滚动后可以继续累积选择，最多 500 项。
3. “选择可见项”只选择当前真实视口中已经载入的素材，不会选择整库或其他未显示的结果。“清空”取消当前选择。
4. 点击“收藏”或“取消收藏”，也可以打开“管理标签”，选择添加或移除标签，输入标签或点选已有标签。
5. 提交后，成功提示会显示更新数量，列表刷新并清空选择；失败时保留选择，方便修正后重试。

批量添加标签会保留其他标签；批量移除只删除指定标签。不存在的标签移除没有副作用。一次操作中的任何素材不存在或标签数量超限时，整个批次都不修改，避免部分成功。

切换搜索、素材库、目录范围、图片筛选或排序会清空选择，避免把上一组结果意外应用到新范围。点击“完成选择”退出选择模式；选择模式内点击卡片用于选择，退出后可以恢复图片预览。

## 图片预览与下载

点击卡片进入预览，用键盘 `←` / `→` 或界面箭头切换，按 `Esc` 关闭。右侧显示格式、尺寸、文件大小、修改日期、标签及相对路径。路径复制受浏览器权限限制时，可手动选中路径复制。

GIF 网格缩略图是首帧，原图预览保留动画。TIFF 通常不能由浏览器直接显示，因此预览使用缩略图，可下载原图查看完整画质。其他格式也受到浏览器解码支持限制；预览失败时仍可尝试“下载原图”。

单张图片超过 256 MiB 文件大小、128 MiB 解码预算或 32,768 像素宽/高时会跳过缩略图；原文件不会被删除。解码失败、原图不可访问或数据目录写入失败也可能影响预览。低配置服务建议保持 1 个图片 worker；同时打开多个大原图会另外消耗浏览器内存。

下载原图保留原文件内容，包括其中的元数据。可以通过“设计作品”组合素材生成新的 PNG；原图编辑或压缩替换、视频管理和 AI 自动标签尚未提供。

## 设计作品：保存布局与合成 PNG

左侧“设计作品”（窄屏也可点顶部画笔按钮）进入设计工作区。第一版提供作品列表、布局 JSON 编辑、保存、预览和 PNG 导出；尚未提供拖拽画布。布局与成品保存在服务器，与原始素材分开。

1. 先在素材库中找到要使用的图片，打开详情，复制“素材 ID”。布局引用编号，不需要填写服务器文件路径。
2. 进入“设计作品”，点击“新建作品”。编辑布局 JSON 的名称、画布大小、背景色与图层。
3. 点击“保存布局”保存新作品或新版本，也可以直接点击“生成预览”，页面会先保存有修改的布局，再提交合成。
4. 等待“已排队，等待合成”/“正在合成图片…”结束，查看预览。调整坐标、尺寸、颜色或文字，再生成新预览。
5. 满意后点击“合成 PNG”，完成后点击“下载 PNG”。较大画布的普通预览会缩小，完整 PNG 使用指定画布尺寸。
6. 下次从作品列表重新打开，继续编辑和保存；同一服务上的 ChatGPT MCP 创建的作品也会出现在列表中，可点击刷新。

下面是可直接粘贴的基础布局。它只使用矩形，可以先验证合成；再用详情中复制的真实素材编号添加 image 图层：

```json
{
  "version": 1,
  "name": "登录界面草稿",
  "canvas": {"width": 960, "height": 540, "background": "#101827"},
  "layers": [
    {"type": "rect", "x": 280, "y": 370, "width": 400, "height": 72, "radius": 16, "color": "#007AFF"}
  ]
}
```

image 图层示例（`123` 必须替换为实际素材编号）：

```json
{"type": "image", "asset_id": 123, "x": 100, "y": 80, "width": 760, "height": 240, "fit": "contain", "opacity": 1}
```

图层按数组顺序从底到顶绘制，坐标从画布左上角开始。`contain` 等比完整放入图层框，`cover` 等比铺满并裁去超出部分，`stretch` 按目标宽高拉伸。这些是成品设计的图层设置，与素材浏览网格的“每行数量”无关。

文字图层需要服务上可用字体，在工作区“布局说明与可用字体”中查看字体编号。也可以使用 `default` 自动选择覆盖所需字符的字体。中文示例：

```json
{"type": "text", "text": "星海", "x": 280, "y": 120, "font_size": 64, "color": "#FFFFFF", "font_id": "default", "max_width": 400, "align": "center"}
```

字体缺少中文字形时，页面会报告错误。管理员可以安装中文字体，或把原始 TTF/OTF/TTC 放入服务数据目录的 `fonts/` 后重启；Docker 镜像已提供中文与拉丁字体。只在浏览器电脑上安装字体不会让另一台服务器使用它。

每边画布最多 4096 像素、最多 64 图层；普通预览最长边 1280，GIF 只取首帧导出静态 PNG。单渲染任务和最多 4 个等待任务用于控制资源占用，队列忙时稍后重试。素材解码受到大小与内存预算限制，超限会报错。

保存后保留旧版本。多人或 ChatGPT 同时修改时，过期布局不会覆盖新版本；出现版本冲突，先查看或重新载入最新布局，再合并自己的修改。切换作品时若有未保存编辑，页面会提示；可以先下载当前草稿 JSON。工作区 JSON 下载保存的是当前 scene，包括尚未提交的修改；任务导出的 layout.json 则包含该任务实际使用的保存版本。

成品 PNG 和布局在重启后保留；未完成的合成任务会标记失败，可以重新生成。布局引用原图而非复制原图，素材被修改、改名或删除后，旧布局可能无法再合成；先重新扫描、确认编号并保存新版本。已经生成的 PNG 不受原图删除影响。备份时保留整个数据目录，并单独备份原素材和需要的系统字体。

要让 ChatGPT 帮你搜索、看素材和调整布局，需要管理员先启用 MCP 并完成 OAuth 连接，见 [ChatGPT MCP 说明](MCP.md)。网页登录不会自动建立这项连接；候选素材拼版与设计预览会按调用发送给模型。

## 移除素材库与文件变化

在素材库管理中选择“移除素材库”，确认“移除索引”后，Picsoc 会删除这个库的索引、收藏、标签和缩略图，**原图仍留在文件夹中**。

再次添加相同目录可以重新索引图片，但不能恢复之前删除的收藏和标签。需要恢复旧元数据时，使用停止服务时制作的整个数据目录备份，见 [运维指南](OPERATIONS.md)。

在文件管理器中新增或修改图片后，通过增量扫描更新；删除图片后，成功重扫会清理对应索引。移动或改名目前视为删除旧素材并添加新素材，原来的收藏和标签不会自动转移。

不要在恢复原图之前启动指向空目录的服务：成功扫描会认为旧文件已不存在并清理索引。数据目录中的 SQLite 文件和缩略图也不要在服务运行时手动修改。

## 界面语言与服务连接

顶部语言选择器可以切换简体中文和 English，当前浏览器会记住选择。另一个浏览器或设备有独立的语言偏好；素材、标签和收藏仍由同一服务共享。

设置 `PICSOC_PASSWORD` 后，打开页面会显示登录页，输入配置的共享密码即可进入；未设置密码时直接进入素材库。登录页也可以切换语言。页面右上角“退出登录”结束当前浏览器会话；会话过期或服务重启后需要重新登录。密码不保存在浏览器持久存储中。

“服务连接异常”时，先确认服务仍在运行，访问地址正确，网络及密码可用，然后点击重试。脚本使用 Basic Auth 时用户名固定为 `picsoc`；远程访问与 HTTPS 配置见 [安全说明](../SECURITY.md) 和 [运维指南](OPERATIONS.md)。
