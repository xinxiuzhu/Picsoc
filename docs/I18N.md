# 界面语言 / Interface languages

Picsoc 默认使用简体中文，支持在顶部切换 English。选择保存在当前浏览器中，刷新页面后继续使用。素材名称、目录路径、素材库名称与用户标签保持原文。

前端使用 i18next 与 react-i18next，翻译随程序一起打包，不需要外部翻译服务或 CDN。HTTP API 根据 `Accept-Language` 返回中文或英文错误说明及合成目录名称；命令行帮助目前使用中文。

## 修改文案

语言文件位于 `frontend/src/locales`：

- `app.*.json`：主界面、筛选、素材库管理。
- `components.*.json`：文件夹选择器、图片预览、标签编辑、首次引导。
- `common.*.json`：页面标题、网络错误。

`zh-CN` 和 `en` 使用相同的翻译 key。React 使用 `t('app.key', {name, count})` 读取文案；变量写作 `{{name}}`、`{{count}}`，保留变量名，翻译周围的文字。英文复数使用 `_one` 和 `_other`，中文通常使用不带后缀的 key。

运行检查与构建：

```sh
cd frontend
npm run check:i18n
npm run build
```

构建会检查两种语言的 key、变量名，以及代码中的固定 key 引用。界面上的计数、文件大小、日期使用当前语言的格式。

## 添加新语言

1. 复制三个现有语言文件，保留 key 和变量名，翻译所有文案。
2. 在 `frontend/src/i18n.ts` 导入并注册新语言资源，扩展 `supportedLanguages`。
3. 在 `App.tsx` 的语言选择器添加对应选项；语言名称使用该语言自己的名称。
4. 扩展 `scripts/check-locales.mjs` 的语言检查，并运行构建。
5. 如需 API 错误说明支持该语言，扩展 `src/i18n.rs` 的请求语言与消息映射。未知语言目前回退到中文。

文案应整句翻译，避免通过多个词片段拼接语序。新语言也需要验证长文本与预览对话框布局。

## For translation contributors

The interface currently supports Simplified Chinese and English. Translations are bundled JSON files in `frontend/src/locales`; no translation service is required at runtime. Keep translation keys and interpolation variables unchanged. Use English `_one`/`_other` plural forms where a count changes the wording. Run `npm run check:i18n` and `npm run build` before submitting a change.

To add a language, provide all three dictionaries, register its resources in `src/i18n.ts`, add a language option in `App.tsx`, and extend the locale checker. The HTTP API also has localized system messages in the Rust backend. User content is never translated.
